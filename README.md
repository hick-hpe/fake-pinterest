# Fake Pinterest 📌

Projeto front-end inspirado no Pinterest, desenvolvido para praticar HTML, CSS, JavaScript e Bootstrap.

## Funcionalidades

- Upload e pré-visualização de imagens.
- Criação de Pins com título, descrição, link e tópicos.
- Gerenciamento de rascunhos.
- Validação de imagens e links.
- Barra de progresso e animações.
- Interface responsiva para desktop e mobile.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
